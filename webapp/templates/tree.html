Which Drawing Are We Working On?

Use a deliberate copy of the equipment model. DWG Tools maps every block in it, then turns the blocks you pick into clean WBLOCK files.

Pick the drawing, then press the arrow. Mapping runs in the background, so Plant 3D stays free while it reads.
Options (Rarely Needed)

Files outside this folder get flagged in the tree. It is filled in from the drawing's path.
Read the drawing with:
Background uses a hidden copy of AutoCAD, so your Plant 3D stays free and nothing pops up. It gives the same tree. Use "My open Plant 3D" only if the background one can't start.
How it works
  1. Map the drawing: every block, what is nested inside it and where it sits. AutoCAD reads a byte copy, never the file itself.
  2. Right-click a block in the tree and choose Create WBLOCK.
  3. Light up: Plant 3D highlights every occurrence and zooms to them. Nothing is drawn into the drawing.
  4. Choose one: the occurrence that sets the coordinates. Click a row, or click it in CAD.
  5. Save: one clean drawing, exploded to layer 0, base point = master 0,0,0. Insert it at 0,0 in the new master and it lands right back here.

Mapping

Starting

Each file is byte-copied first and AutoCAD reads only the copy. Every original is fingerprinted (SHA-256) before and after. A large drawing can take a few minutes.

Tick blocks to merge them into one WBLOCK. Double-click a row to open it; arrow keys and Space work too.
